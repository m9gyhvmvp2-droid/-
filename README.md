# Trace — Photo to Your Art (v2 prototype)

写真を下敷きにして、自分で描いて作品にするWebプロトタイプです。v2では「初心者でも描きやすいこと」と「少しアナログっぽい仕上がり」を強化しました。

## v2で追加した主な機能
- **ズーム / 移動**
  - 安全な操作方式として、`✏️描く / ✋移動` のモード切り替えを追加
  - ズームスライダーで 100%〜400%
- **12色 Auto Color パレット**
  - 写真から自動で12色を抽出
  - 1ストローク中は同じ色で描画
  - 生成されたパレットをそのまま手動選択可能
- **4種類のブラシ**
  - 水彩 / 色鉛筆 / クレヨン / スプレー
- **かんたん塗りモード**
  - `なぞる` と `かんたん塗り` の2モード
  - かんたん塗りではタップで領域にベース色を入れられる
  - 細かさは `かんたん / ふつう`
- **紙の質感**
  - 画用紙 / 水彩紙 / スケッチ紙
  - 強さ調整つき
